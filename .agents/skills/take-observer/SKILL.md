# Take Observer

Use this skill to silently observe background processes, monitor async job executions, and provide synthesis reports without disrupting user flow.

## Observer Protocol
1. **Silent Log Inspection**: Inspect log files and task output silently in the background (`manage_task`, log file inspection).
2. **Professional Synthesis**: Summarize progress, completion status, or failures cleanly in natural language without unneeded noise.
3. **Workflow Optimization**: Track background servers (e.g., Python proxy server, background jobs) and ensure non-blocking operation.
