# Cyber Power

Use this skill whenever handling complex coding tasks, debugging runtime issues, or making non-trivial codebase modifications.

## Core Rules & Protocol
1. **Planning First**: Formulate a complete mental model and implementation plan before modifying files.
2. **Empirical Log Diagnosis**: Inspect full error logs and tracebacks before forming hypotheses. Never patch symptoms blindly.
3. **Verification**: Always execute automated build/test commands to verify code changes before claiming task completion.
4. **No Superficial Patches**: Never swallow exceptions or bypass failing tests. Resolve root causes.
