# Sınırsız Hafıza (Unlimited Memory)

Use this skill to maintain persistent project context across sessions, eliminating the need for the user to re-explain project architecture every morning.

## Core Protocol
1. **Knowledge Retrieval**: Check codebase knowledge graphs, Knowledge Items (`<appDataDir>\knowledge`), and local memory before starting research.
2. **Context Persistence**: Store critical project configurations, API keys, environment settings, and state mappings in local configuration artifacts.
3. **Continuous Alignment**: Maintain exact variable names, API contracts, and user preferences across turns.
