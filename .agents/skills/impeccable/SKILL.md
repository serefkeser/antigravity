# Impeccable

Use this skill whenever designing, building, or modifying web applications, user interfaces, or frontend components.

## Design Excellence Standards
1. **Rich Aesthetics**: WOW the user with modern color palettes, sleek dark modes, subtle glassmorphism, and responsive layouts.
2. **Typography & Motion**: Use clean modern typography and smooth micro-animations for interactive elements.
3. **No Low-Quality Placeholders**: Always create polished UI components without raw default browser styles.
4. **Local State Hygiene**: Keep transient UI state isolated in component state before committing changes.
